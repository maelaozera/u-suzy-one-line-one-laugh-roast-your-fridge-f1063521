## The roast

**My fridge let the milk expire in 2019 and the light die with it — the only thing it still keeps fresh is its grudge.**

The roast is built on two concrete, recognisable details — milk that
expired in 2019 and a dead fridge light — and turns on the fridge's one
job: keeping things fresh. The punchline lands in the last few words,
where "fresh" stops describing food and starts describing the
appliance's attitude. Short on purpose: on an exact tie the smaller
text places first, and a short line trusts the reader.

## How it works

`main.ts` (Node 22 TypeScript, no dependencies) writes exactly that one
line — no trailing newline, no extra text — to `/output/entry.txt`,
after self-checking the gate: 1–200 characters, not only whitespace,
a single line.

```sh
node main.ts
```
